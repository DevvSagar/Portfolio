# Sagar Singh — Portfolio

Personal portfolio website for **Sagar Singh** (DevvSagar), Backend Software Engineer.

- **Live Website**: [https://devvx.in](https://devvx.in)
- **Tech Stack**: React 19, Vite, Material UI v6, Bootstrap 5, Custom ASCII Engine
- **Deployment**: GitHub Pages (Custom Domain `devvx.in` via GitHub Actions)

## 🛠 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Generate static production build
npm run build
```
