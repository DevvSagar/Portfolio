# Sagar Singh — Portfolio

Personal portfolio website for **Sagar Singh** (DevvSagar), Backend Software Engineer.

🌐 **Live Website**: [devvx.in](https://devvx.in)

---

## 🛠 Tech Stack

- **Frontend**: React 19, Vite, Material-UI, Bootstrap 5
- **Animations**: Custom HTML5 Canvas ASCII Particle Engine
- **Deployment**: GitHub Pages (Custom Domain `devvx.in` via GitHub Actions)

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
